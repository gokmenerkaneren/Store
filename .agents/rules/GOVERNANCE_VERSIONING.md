# GOVERNANCE VERSIONING

## Sürümleme

`MAJOR.MINOR.PATCH`

- MAJOR: çalışma modelini değiştiren breaking governance değişikliği
- MINOR: yeni protokol/skill/capability
- PATCH: hata düzeltmesi veya açıklık iyileştirmesi

## Değişiklik akışı

`PROPOSAL → IMPACT ANALYSIS → REVIEW → APPROVAL → CHANGE → VALIDATION → CHANGELOG`

Agent sistemi kendisini bu akış dışında değiştirmez.
