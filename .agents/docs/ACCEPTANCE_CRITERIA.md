# ACCEPTANCE CRITERIA — GOVERNANCE v1.0

## Must pass

- [ ] Gravity görevi sınıflandırabiliyor.
- [ ] Activation matrix uygulanabiliyor.
- [ ] En az bir multi-agent handoff dry-run başarılı.
- [ ] Conflict senaryosu bloklama üretiyor.
- [ ] Approval-required senaryosu implementasyonu durduruyor.
- [ ] Build/test failure recovery senaryosu escalation üretiyor.
- [ ] Haftalık review çıktısı üretilebiliyor.
- [ ] Governance değişiklikleri versioned.

## Must not happen

- [ ] Kaynaksız mimari karar uydurma.
- [ ] Onaysız L3 değişikliği.
- [ ] Çelişkili doküman varken sessiz implementasyon.
- [ ] Sınırsız hata tekrar denemesi.
