# TRUTH MODEL

Governance'ın amacı dokümanları çoğaltmak değil, her bilginin tek bir sahibini korumaktır.

- Architecture facts → ARCHITECTURE.md
- Business rules → BUSINESS_RULES.md
- Database facts → DATABASE_MAP.md
- Project progress → PROJECT_STATUS.md
- Context → PROJECT_CONTEXT.md
- Decisions → ADR/
- Agent behavior → rules/ + skills/ + protocols/
