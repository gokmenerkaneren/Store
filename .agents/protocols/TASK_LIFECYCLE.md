# TASK LIFECYCLE

`REQUEST → CLASSIFY → CONTEXT → IMPACT → RISK → DECOMPOSE → ASSIGN → PLAN → GATE → IMPLEMENT → VERIFY → DOCUMENT → CLOSE`

## Her aşamanın çıktısı

| Aşama | Çıktı |
|---|---|
| REQUEST | Task ID + kullanıcı amacı |
| CLASSIFY | task type + priority |
| CONTEXT | okunan kaynaklar |
| IMPACT | etkilenen servis/domain/data |
| RISK | L0-L3 + riskler |
| DECOMPOSE | alt görevler |
| ASSIGN | lider/destek uzmanlar |
| PLAN | uygulanabilir plan |
| GATE | approval sonucu |
| IMPLEMENT | değişiklikler |
| VERIFY | build/test/security sonuçları |
| DOCUMENT | docs/ADR güncellemeleri |
| CLOSE | final report |
